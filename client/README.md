# Vestly Client

React frontend for Vestly, built with TanStack Start, TanStack Router, TypeScript, Tailwind CSS 4, and Motion.

## Commands

```bash
npm install
npm run dev
npm run build
npm run lint
npm run check
```

The app expects the backend at `http://localhost:8000` unless `VITE_API_URL` is set in `.env.local`.

See the root `README.md` for the full project overview.
